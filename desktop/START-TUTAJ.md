# FivemShop Command Center 1.3 — Windows

1. Zamknij starszą wersję FivemShop.
2. Uruchom instalator FivemShop-Setup-1.3.0.exe. Program zainstaluje się dla Twojego konta Windows i utworzy skrót FivemShop.
3. Dalej uruchamiaj aplikację ze skrótu. Nie korzystaj ze starego pliku portable.
4. Wybierz swoje konto, kliknij „Wyślij kod na Discorda” i otwórz kanał logowania. Kliknij „Pokaż mój kod”, a następnie wpisz kod w aplikacji.

## Aktualizacje

Program sprawdza nowe wersje przy uruchomieniu i co 4 godziny podczas pracy. Możesz też kliknąć „Sprawdź aktualizacje”. Kiedy aktualizacja jest dostępna, wybierz „Pobierz aktualizację”, a po pobraniu „Uruchom ponownie i zaktualizuj”. Zapisz wcześniej szkic oferty i niewysłaną odpowiedź. Program nie zrestartuje się sam podczas pracy.

Ta jednorazowa instalacja dodaje mechanizm aktualizacji. Wersje portable 1.2 i starsze nie mają go i nie mogą samodzielnie pobrać tego mechanizmu.
